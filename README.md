# Reasonix skills

Skills and MCP manifests published to the Reasonix community market.
Each folder is one package; the market pins every entry to a full commit SHA.

| Package | What it does |
|---|---|
| `skill-lint` | Audits a skill folder before publishing or installing it. Read-only. |
| `pptx-deck` | Plans and builds a PowerPoint deck from your material: claim-per-slide outline, plain wording, a bundled script that writes the .pptx. Needs `python-pptx`; no network. |
